Install StarterApp

Add a StarterApp icon to your iPhone Home Screen using this configuration profile.

Download StarterApp Profile

Finish installation on iPhone

  1. Open this page in Safari on your iPhone.
  2. Tap Download StarterApp Profile.
  3. Open the iPhone Settings app. Tap Profile Downloaded near the top (or go to General → VPN & Device Management).
  4. Choose the StarterApp profile and tap Install.
  5. Return to your Home Screen and tap the StarterApp icon.

What this installs: a removable Home Screen web shortcut that opens StarterApp full-screen. It is not a native iOS app and does not install an IPA, device-management enrollment, certificate, or access to personal data.

If iOS does not offer profile installation, use Safari's Share → Add to Home Screen instead.
